🚀 FLY.IO DEPLOYMENT (RECOMMENDED)
=================================================================
Pros: Always on, persistent storage, great for SQLite
Cost: ~$4.50/month (hobby plan + IPv4 + 3GB volume)

Prerequisites:
1. Credit card for Fly.io (needed to prevent auto-stop)
2. Git repository

Steps:
1. Install flyctl:
   brew install flyctl
   # or download from https://fly.io/docs/hands-on/install-flyctl/

2. Sign up & login:
   fly auth signup
   fly auth login

3. Launch the app:
   cd /path/to/survey
   fly launch --no-deploy --name your-survey-app
   
4. Create persistent volume:
   fly volumes create survey_data --size 3 --region sjc

5. Allocate IPv4 (required for DNS):
   fly ips allocate-v4 --yes

6. Set environment variables:
   fly secrets set ADMIN_PASSWORD="your-secure-password"
   fly secrets set REFERRAL_CODES="CODE1,CODE2"
   
7. Deploy:
   fly deploy

8. Your app will be live at:
   https://your-survey-app.fly.dev

9. To keep it always running (required):
   - Ensure auto_stop_machines = false in fly.toml ✓
   - Ensure min_machines_running = 1 in fly.toml ✓

-------------------------------------------------------------------
USEFUL COMMANDS
-------------------------------------------------------------------

# View status
fly status

# View logs
fly logs

# SSH into the machine
fly ssh console

# Restart the app
fly machine restart <MACHINE_ID>

# Deploy updates
git add .
git commit -m "Your changes"
fly deploy

# Scale resources (if needed)
fly scale memory 512  # Increase to 512MB
fly scale count 2     # Add more instances

-------------------------------------------------------------------
TROUBLESHOOTING
-------------------------------------------------------------------

Machine keeps stopping?
→ Make sure you have a credit card on file
→ Check auto_stop_machines = false in fly.toml

DNS not working?
→ Make sure IPv4 is allocated: fly ips list
→ May take 10-15 minutes to propagate

Can't access the site?
→ Add to /etc/hosts temporarily:
  echo "<YOUR_IPV4> <your-app>.fly.dev" | sudo tee -a /etc/hosts
